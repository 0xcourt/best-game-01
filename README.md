ANGKOT RUSH — a top-down 2D driving game: drive an angkot around a city route, pick up passengers at halts, drop them at their destinations for fares, chase the shift setoran target, and manage fuel across 3 shifts.

## Run it

```sh
python3 -m http.server 8080 --directory game
```

Then open http://localhost:8080. Keyboard: arrows/WASD to drive, Space to brake, H to honk, P to pause. Mouse works for all menus.
